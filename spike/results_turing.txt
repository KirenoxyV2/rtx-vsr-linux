# host: WSL2 Ubuntu 26.04, Windows driver 610.88 (KMD) / CUDA UMD 13.3, nvidia-vfx 0.2.0.0 (pip wheel)

# KEY FIX: on WSL2, NGX's dlopen("libcuda.so") (unversioned) fails because WSL
# ships only /usr/lib/wsl/lib/libcuda.so.1 and the ldconfig cache has no
# unversioned entry. Fix (one-time, root):
#   ln -sf /usr/lib/wsl/lib/libcuda.so.1 /usr/lib/x86_64-linux-gnu/libcuda.so && ldconfig
# Without it: NvVFX_Load fails (code -1) and the process double-frees/aborts.
# With it: ALL modes load and run on Turing. The model lib bundles cubins for
# sm_75 (41), sm_80 (69), sm_86 (10), sm_89 (10) — Turing IS supported upstream
# of the "experimental" gate; the gate's thermal warning still applies.
